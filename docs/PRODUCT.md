## 1. 赛题原文要求拆解

赛题给的功能清单是"必做项 + 进阶项"，我们逐条翻译成可验收的行为：

| 赛题表述 | 我们的实现 | 验收方式（评委可现场操作） |
|---|---|---|
| 文章获取与阅读 | 粘贴正文导入 + 3 篇内置示例 | 点「导入文章」粘贴任意英文，立刻可读 |
| 支持字号与主题切换 | 字号 14–26px、行距 1.4–2.4、三套主题 | 顶栏 ⚙ → 拖滑块，正文实时变化 |
| 阅读流畅性与学习深度兼顾 | **流畅 / 学习双模式** | 顶栏一键切换，标注层整体收起/展开 |
| 点击查词 / 划词翻译 | 点单词 → 气泡显示音标、词性、中文释义、原句 | 点任意单词，0.1s 内出结果（离线词表） |
| 生词本与生词卡 | 生词卡含原句 + 出处，可回到原文 | 生词本 → 卡片 → 「回到原文」跳转 |
| 生词卡日历 / 复习 | 间隔重复 + 日历热力图（模块 C） | 复习队列打三档评分，日历格子变色 |
| 阅读进度与打勾 | 段落级勾选 → 文章百分比 → 侧栏进度条 | 勾两段，侧栏百分比同步变化 |
| 长句解析 | 切分句子成分 + 中文讲解（模块 D） | 学习模式下点句子，弹出结构分析 |
| TTS 朗读 | 逐句朗读 + 当前句高亮（模块 E） | 点朗读，正文逐句高亮并自动滚动 |
| 数据持久化 | localStorage + 导出/导入备份 | 刷新页面数据不丢；导出 JSON 再导入可恢复 |

## 2. 用户与场景

**目标用户**：备考雅思/托福/考研英语、需要长期读外刊的大学生；以及需要精读英文材料的职场人。

**三个典型场景**：

1. **通勤路上通读**（3–8 分钟）→ 用**流畅模式**读一篇，不查词，只勾"本文读完"。
2. **晚上精读一段**（20 分钟）→ 用**学习模式**，把 5–10 个生词点成卡，遇到长句点开看结构。
3. **第二天复习**（5 分钟）→ 打开生词本，按到期顺序过一遍卡片，三档评分。

**场景 3 是留存的关键**：只查词不复习等于没学，所以复习队列和日历是必做项，不是锦上添花。

---

## 3. 差异化：我们只押一个点

同类工具（欧路词典、Readlang、LingQ）都在做"阅读 + 查词"，我们不试图在词库规模或翻译质量上比过它们。我们押的是：

> **同一个词，在"读得顺"和"学得深"两种状态之间无缝切换，且切换不丢失上下文。**

具体体现为三个别人少做的细节：

1. **双模式共享同一份标注数据**：流畅模式攒的生词，切到学习模式立刻能在原文看到下划线定位；
2. **生词卡永远带原句与出处**：复习时不是背孤立的词，而是回到那句话，还能一键跳回原文段落；
3. **释义来源始终可见**：每个释义标明"内置离线词表 / 免费在线词典"，不假装自己什么都知道 —— 这既是诚实，也是离线可用的技术保证。

## 5. 明确不做的事（Non-goals）

写下来是为了防止范围膨胀：

| 不做 | 原因 |
|---|---|
| 后端服务 / 用户账号 / 云同步 | 违背"零配置可跑"，且 30 分闭环风险剧增 |
| 付费翻译 API 作为主路径 | 评委没有 key，会直接跑不起来 |
| URL 自动抓取全文 | 跨域需代理服务；外刊多有付费墙；粘贴正文已够用 |
| 移动端 App / 浏览器插件 | 时间不够，Web 响应式已覆盖手机浏览器 |
| 自研 NLP 模型 | 用规则 + 可选 LLM 增强即可，投入产出比更高 |
| 用户导入内容的云端存储 | 版权风险，且无后端 |
